Hardware Photos

This folder contains photographs documenting the physical hardware used in the HP ProDesk 400 G6 Mini Proxmox homelab project.

The photographs will provide a visual record of the hardware configuration and any upgrades or changes made during the build.

Planned Photographs

* Internal chassis and motherboard.
* Intel Core i5-10500T processor and cooling assembly.
* Installed RAM modules.
* 256GB NVMe primary SSD.
* 120GB Kingston SSDNow 300 SATA secondary SSD.

Photo Documentation

Photographs will be added as the project progresses.

Each image should have a clear filename describing what it shows. Where appropriate, photographs will also be referenced from the relevant hardware documentation.
